# План ModuleMessengerHub

Хаб уведомлений MikoPBX: сам собирает события АТС и модулей и отправляет их в Telegram и MAX.

Статус: **этап 0 — каркас** (18.11.2026). Код функций ещё не написан, есть устанавливаемый пустой модуль,
сборка, тесты и документация.

## Правило для агентов и разработчиков

План — источник истины по поведению модуля. Меняете поведение — сначала правите план (или фиксируете
решение в `11-open-questions.md`), потом код. Закрытый этап отмечается в `09-roadmap.md`.
