# 06. REST API v3 и интерфейс

## REST API

База: `/pbxcore/api/v3/module-messenger-hub`. Конверт ответа — `PBXApiResult`. Ресурсы — существительные,
CRUD через стандартные методы; `:action` — только для переходов состояния, которые не CRUD.
Каждый ресурс — свой каталог `Lib/RestAPI/{Resource}/` (Controller, Processor, DataStructure, Actions).
Все ключи OpenAPI-описаний — в `Messages/en.php` и `Messages/ru.php` (skill `mikopbx-module`,
скрипт проверки переводов REST).

| Ресурс | Методы | Заметки |
|---|---|---|
| `/settings` | GET, PATCH | глобальные настройки |
| `/bots` | GET list, GET {id}, POST, PATCH {id}, DELETE {id} | `token` только во входе POST/PATCH; в ответах — `token_hint` |
| `/bots/{id}:check` | POST | проверка токена (`getMe` / `GET /me`), обновляет `status` |
| `/chat-discoveries` | POST (старт сеанса для бота), GET {id} (найденные чаты), DELETE {id} (остановить) | сеанс 5 минут |
| `/recipients` | GET list, POST, PATCH {id}, DELETE {id} | ручное добавление и подтверждение найденных |
| `/rules` | GET list, GET {id}, POST, PATCH {id}, DELETE {id} | |
| `/test-messages` | POST | отправить тест выбранным получателям; ответ — результат по каждому |
| `/sources` | GET list | доступность, последний опрос, ошибка; PATCH {id} — вкл/выкл источник |
| `/deliveries` | GET list | история отправок (Outbox + событие), фильтры: статус, тип, период; постранично |
| `/deliveries/{id}:retry` | POST | повторить `failed` |

Права: все ресурсы — только администратор. В ModuleUsersUI — отдельная группа прав модуля,
по умолчанию закрыта для всех ролей кроме администратора.

## Интерфейс (Volt + jQuery + Fomantic UI)

Пункт меню «Уведомления в мессенджеры» (группа `integrations`). Вкладки одной страницы:

1. **Боты** — список, «Добавить бота» (канал, токен), статус проверки, «Подключить чат».
   Для MAX — подсказка, что бота создаёт организация на business.max.ru и проходит модерацию.
2. **Получатели** — чаты по ботам, привязка личного чата к сотруднику, вкл/выкл.
3. **Правила** — список и форма правила (типы событий, важность, фильтры, получатели, маскирование).
4. **Источники** — какие источники доступны, их состояние, вкл/выкл.
5. **История** — последние отправки, статусы, ошибки, «Повторить».
6. **Настройки** — внешний адрес АТС, прокси, CA для MAX, срок хранения, маскирование по умолчанию,
   предупреждение о передаче персональных данных.

JS: один файл на страницу в `public/assets/js/src/`, сборка Babel. Тексты — только через переводы.
