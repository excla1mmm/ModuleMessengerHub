# 07. Безопасность и персональные данные

## Токены ботов

- Хранятся только в `m_MessengerHubBots.token` в БД модуля (файл доступен root/www АТС).
  Шифрование ключом, лежащим на той же АТС, не даёт реальной защиты — не делаем вид, что защищаем;
  вместо этого строго контролируем выход наружу.
- REST API и интерфейс **никогда** не возвращают токен: только `token_hint` (последние 4 символа).
  Замена токена — новым значением; прочитать старый нельзя.
- Telegram передаёт токен в URL → `HttpTransport` не пишет URL, заголовки и тела запросов в лог;
  ошибки нормализуются в коды (`telegram.403.blocked`, `max.attachment_not_ready`, `http.timeout`).
- Тест-контракт: ни один ответ API, ни одна строка лога, ни `last_error_code` не содержат токен
  (`Tests/check-*-secret-*`).

## Права

- Все ресурсы модуля — только администратор (ModuleUsersUI: закрыто по умолчанию).
- Собственный ключ API хаба (решение Q1): `full_permissions='0'`, в `allowed_paths` — только пути включённых
  источников со значением `read`, без `admin` и `write`. Открытое значение — секрет
  хаба наравне с токенами ботов: не отдаётся API, не логируется. В ядре хранится только bcrypt-хэш.
  Описание ключа в списке ключей ядра: «ModuleMessengerHub (read-only sources)». Удаляется при отключении хаба.

## Персональные данные

- Во внешний мессенджер уходят номер клиента, имя сотрудника, тексты (сводки ИИ, цитаты), записи.
- По умолчанию хаб **выключен**, правила созданы выключенными.
- В настройках — явное предупреждение о передаче данных во внешний сервис.
- Маскирование номера (глобально и в правиле), отключение вложений в правиле.
- История в БД модуля хранится ограниченный срок (по умолчанию 30 дней).

## Сеть

- Исходящий HTTPS к `api.telegram.org`, `platform-api2.max.ru` и адресам загрузки MAX.
- Прокси HTTP/HTTPS/SOCKS5 в настройках.
- TLS всегда с проверкой сертификата; для MAX — корневой сертификат НУЦ Минцифры (файл в модуле
  или путь в настройках).

## Входящие данные

Тексты из событий (имена, расшифровки, названия чатов) — недоверенные: экранирование под разметку
канала, ограничение длины, без интерпретации как команд.
